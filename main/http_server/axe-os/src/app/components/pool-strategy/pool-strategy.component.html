Timed pool sessions are not available yet. A flow like “mine BCH for six hours, then restore BTC” needs the switch and the timed restore to run on the device itself. NeuralAxe has no on-device pool scheduler today, and a browser timer cannot be trusted — it stops when this tab is closed, the PC sleeps, or Wi-Fi drops, and would leave the wrong pool active. Rather than present an unreliable timer as an autonomous schedule, timed sessions are deferred to a proposed firmware sub-phase. Manual switching, verification, rollback and restore are fully available below.
