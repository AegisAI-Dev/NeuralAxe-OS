Timed Pool Session

Run one unattended, time-boxed session on a different pool and come back automatically. The device captures its own current pool configuration, applies the target transactionally, verifies it live before authorising any mining on it, and treats the return to your original pool as mandatory. Your existing pool password is never read, sent or changed.

This dashboard only submits requests and reads back what the device reports. The device decides everything, and its status is the only proof of what actually happened.
