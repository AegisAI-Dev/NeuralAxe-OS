How attribution works

  • Provider-reported the block-data provider attributes this block to a pool — public evidence, not proof.
  • Strong coinbase match the coinbase tag clearly names a known pool.
  • Probable a likely pool from alias/domain evidence, or downgraded conflicting provider vs coinbase evidence.
  • Unknown pool a coinbase is present but no pool could be identified.
  • Unattributed no coinbase/evidence was available from the provider.

Public providers report evidence, not proof, so the strongest state shown here is “Provider-reported”. “Confirmed” is reserved for a future authoritative source (an explicit pool, Stratum or node provenance contract) and is never shown for public-provider data.

Pool attribution is based on public block and coinbase evidence. It does not prove that this individual NeuralAxe device found the block.
